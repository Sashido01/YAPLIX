# Правила взаимодействия / Code of Conduct

В командной работе над YAPLIX придерживаемся профессионального общения.

- Обсуждаем идеи, код и факты; не используем персональные оскорбления, травлю и дискриминацию.
- При несогласии формулируем конкретный аргумент и предлагаем проверяемую альтернативу.
- Не раскрываем чужие личные данные, переписку и информацию, переданную конфиденциально.
- Признаём вклад других участников и корректно атрибутируем сторонние материалы.
- Споры по процессу сначала решаем внутри команды; публичные Issues и PR используем для вопросов, которые допустимо обсуждать открыто.

Правила распространяются на обсуждения в Issues, Pull Requests и в иных пространствах, где участники представляют проект. Контакт для конфиденциальных сообщений будет определён командой до публичного запуска продукта; пока не публикуйте чувствительные сведения в Issues.
