# Продукт и контекст

**YAPLIX: «Ты придумал. Теперь играй».** Команда из [двух участников](../AUTHORS.md) разрабатывает платформу генерации браузерных игр по текстовому описанию для «ИТ-спринт 2026», кейс Билайна.

Основной сценарий: идея → самостоятельный HTML5 → техническая проверка → игра → изменение → история и экспорт. Возможности интегрированного кандидата перечислены в [статусе продукта](release-status.md); [демонстрация](demo-readiness.md) занимает 3–5 минут.

Arena, безопасная подготовка частной сети и обновлённое оформление объединены в релиз-кандидат. До ревью main не меняется. Автоматическая эволюция на основе аналитики, коммерческие кампании, публичный multiplayer и многопользовательская изоляция не заявлены реализованными.

[Исходная концепция](archive/project-brief-2026-10-13.md) сохранена как история: прежний состав команды, названия будущих модулей и календарь не являются актуальными обязательствами. Официальные сроки и права определяются документами организаторов; эта подготовка не сверяет закрытые материалы.
