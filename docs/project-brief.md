# YAPLIX — концепция и архитектурный ориентир

_Обновлено: 13 октября 2026. Источник требований и дат — задания команды TASK-001/002; официальное положение конкурса этим документом не проверяется._

**YAPLIX: «Ты придумал. Теперь играй».** Платформа создания, изменения и распространения браузерных игр с помощью искусственного интеллекта.

## Обязательный результат

Пользователь вводит описание обычным текстом. LLM генерирует код новой HTML5-игры, а не выбирает шаблон; формат предназначен для автономных браузерных игр. Механику и совместимость конкретного WebView проверяют отдельно. Изменения игры сохраняются как отдельные версии с историей.

Бонусные направления: адаптация к возрасту и аудитории, использование игровой аналитики, доработка новыми промптами, графика и звуки, touch-управление, история и галерея, разные жанры. Они не заменяют обязательный результат.

## Направления продукта

| Модуль | Предполагаемая ответственность |
| --- | --- |
| Game Generator | Описание → генерация кода → проверяемый артефакт HTML5-игры |
| YAPLIX Analytics | Сбор и анализ игрового опыта и результатов |
| Evolution Engine | Создание следующих поколений игр с улучшенными механиками на основе опыта |
| Social & Media | Распространение, приглашения, достижения и медиа |
| Business Campaigns | Игровые кампании и аналитика эффективности для бизнеса |

YAPLIX Play — будущее пользовательское направление; YAPLIX Studio — будущие инструменты кампаний для бизнеса. GameDNA — историческое внутреннее имя концепции Evolution Engine.

В TASK-002 реализован протокол игровых событий v1: game_ready, game_started,
score_changed, game_won, game_lost, session_ended, game_error. Есть SQLite,
версии, сессии, аналитика и сравнение; автоматическая эволюция пока отсутствует.
Схема и границы — в [архитектуре](architecture.md). Во время gameplay сервер
и телеметрия остаются необязательными.

## Текущая граница

Собственные frontend/generator/API/SQLite/runtime в одном репозитории; cloud
primary, OpenRouter free only, Telegram тот же UI с HMAC/HTTPS. History/export/backup
независимы от чужих проектов. Social/Media/Business — дальнейшие направления.
Автоматической эволюции и причинного доказательства улучшений пока нет.
[Архитектура](architecture.md), [техническое состояние](submission-status.md). Права использования определяются отдельно. Private сохраняется, публичного релиза нет.
