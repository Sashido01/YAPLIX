# Как YAPLIX проверяет игру

Проверка решает, можно ли сохранить новую версию, но не сертифицирует любую игровую механику. Полный контракт и ограничения наблюдения: [Canvas/WebGL](canvas-rendering-contract.md).

## Путь результата

`generationMessages → prepareDocument → static validation → browserCheck → checkFullHtml → parseArtifact → Store.save`.

Проверяются самостоятельность HTML, ограничения ресурсов, выполнение JavaScript и наблюдаемое рисование. Disposable Chromium работает offline с OS sandbox, очищенным окружением и opaque iframe/CSP. Генерируемый код не исполняется в Node. Сеть, всплывающие окна и ошибки выполнения блокируют приём.

Для новых LLM create/edit и повторной проверки checkpoint обязателен `canvas-webgl-strict-v2`. Видимые DOM-кнопки, HUD, SVG и текст внутри игры не допускаются; технические невидимые элементы разрешены. Неуверенность в видимости/активности Canvas блокирует Save/Ready с NOT_VERIFIED, сохраняя черновик. Исторические версии продолжают открываться и экспортироваться без изменений.

## Размеры и метаданные

Full HTML gate использует 320×700, 390×700 и 844×390 при DPR 2; legacy startup gate — 320×700 и 390×700. Parser сохраняет scope и точные профили. Старые записи с двумя профилями читаются в режиме saved metadata, без приписывания landscape.

Ранее несовместимость трёх профилей с parser блокировала сохранение. Исправление PR #46 уже включено в main; повторный путь job → checker → parse → SQLite/API проверяется в [browser-metadata.test.ts](../tests/browser-metadata.test.ts). [Историческое воспроизведение](archive/micro-036-2-docs-audit.md) больше не является текущим блокером.

## Что означает результат

| Наблюдение | Граница вывода |
| --- | --- |
| HTML/JS загружается, Canvas рисует, ограниченный input меняет кадр | Техническая совместимость в окне проверки |
| Нет достаточных данных о рисовании или видимости DOM | NOT_VERIFIED; новая версия не сохраняется |
| Найден запрещённый DOM или runtime error | Отказ с диагностикой |
| Пройдены мобильные профили | Эмуляция браузера, не физические Android/iOS/WebView |
| Существуют score events или меняются пиксели | Это ещё не доказательство правил, честности счёта, победы/поражения и Restart |

Gate ограничен общим deadline 18 секунд. Он не перебирает все будущие состояния произвольной игры. Незнакомая раскладка или редкая анимация могут не дать достаточного evidence. Полная игровая проверка требует отдельного сценария с реальными действиями.

## Ошибки и восстановление

Job сохраняет исходный запрос, полный raw checkpoint в пределах квоты и диагностический статус. Отказ Canvas/DOM не разрешает автоматический LLM repair или fallback. Продолжение полного checkpoint повторяет локальный gate без нового inference; у ChatGPT второй POST запрещён на всём lifetime job. Детали настроек и бюджетов: [разработка](development-setup.md), [ChatGPT](chatgpt-setup.md).

Основные regressions: [строгая metadata](../tests/strict-metadata.test.ts), [Canvas](../tests/canvas-contract.spec.ts), [DOM и состояния](../tests/strict-canvas.spec.ts), [автономный экспорт](../tests/strict-offline.spec.ts). Они используют авторские fixtures и синтетические transport: это не новый LIVE-результат.

[Прежние подробные заметки](archive/validation-notes.md) сохранены как история, [известные ошибки](known-errors.md) — как проверенные способы диагностики.
