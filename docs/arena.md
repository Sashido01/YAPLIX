# Arena — один QR и общий рейтинг

**Кандидат на интеграцию, ещё не main.** На 21 октября 2026 реализация находится в [Draft PR #53](https://github.com/Sashido01/YAPLIX/pull/53), head `364bd2194890df3a205f82086402b652c6f9b372`. Этот документ не добавляет Arena в приложение и не разрешает merge.

Ведущий выбирает неизменяемую версию → открывает «Общий рейтинг» → запускает комнату в частной LAN → показывает один QR. Участники вводят разные ники и играют независимые партии одного HTML. Сервер сохраняет лучшие завершённые результаты; после рестарта рейтинг восстанавливается. Это не синхронный multiplayer.

Версия должна поддерживать score-v1; несовместимая игра получает сообщение «Рейтинг недоступен». Для демонстрации в ветке есть авторский «Меткий бросок», явно без LLM. Порт Arena — 52605; обычный QR одной игры остаётся на 52604.

[Зафиксированная инструкция и контракт кандидата](https://github.com/Sashido01/YAPLIX/blob/364bd2194890df3a205f82086402b652c6f9b372/docs/arena.md) описывают запуск, migration snapshot v3, привязку versionId/hash, комнаты, score bridge и ограничения. Рейтинг доверяет клиентским событиям и не является античитом.

По PR описаны локальные тесты десяти изолированных браузерных клиентов и сохранения после рестарта. В Issue #55 владелец сообщил об успешной игре двух физических телефонов после ручной настройки частного Firewall. Это HUMAN_REPORTED, не независимый прогон этой подготовки и не гарантия вместимости или всех мобильных платформ.

Настройка LAN при первом запуске подготовлена отдельно в [Draft PR #56](https://github.com/Sashido01/YAPLIX/pull/56), base `codex/arena-mvp`, head `1d7c72907497b50eb38640d2a6ee91e0e7874cc6`. После решения по Arena необходима новая проверка интеграции; реальный elevated Apply/rollback ещё не подтверждён. [Все решения перед релизом](release-status.md).
