# YAPLIX — продуктовая презентация

Восемь слайдов о создании браузерных игр с помощью искусственного интеллекта. [HTML-презентация](presentation.html).

## Слайд 1. YAPLIX — от идеи к браузерной игре

Пользователь описывает игру обычными словами. YAPLIX генерирует HTML5, проверяет его, исправляет подтверждённые ошибки и сохраняет версию.

**Идея продукта:** «Мы превращаем текстовую идею в игру, которую можно запустить прямо в браузере».

## Слайд 2. Игра по вашей идее

- Естественноязыковой запрос без ручного программирования.
- Настоящий playable-результат: начало, управление, игровой цикл, завершение.
- Автономный HTML5 Canvas/WebGL для дальнейшего встраивания в WebView.

**Пример запроса:** «замути змейку для бабушки» — крупные элементы и понятное управление.

## Слайд 3. Автоматический процесс

Ограниченное автоматическое исправление доступно для поддерживаемых маршрутов.

```text
Идея → выбранная LLM → автономный HTML
                        ↓
              защищённая проверка
                 ↙            ↘
          подтверждённый        PASS
          исправимый дефект       ↓
                 ↓         сохранённая версия
        repair той же LLM
                 └────→ повторная проверка
```

Автоматический repair — часть генерации; пользовательский редактор является отдельным режимом. Число вызовов на задание ограничено; неизвестный сетевой результат не дублируется.

## Слайд 4. Пользовательский путь

1. Выбрать модель и ввести идею.
2. Получить созданную игру в библиотеке и играть.
3. Попросить изменить игру — новая версия проходит техническую проверку; ограниченное исправление доступно при поддержке выбранного маршрута.
4. Экспортировать автономный HTML, использовать доступные способы запуска на другом экране.

Библиотека хранит созданные вами игры и их версии.

## Слайд 5. Архитектура

- **Node.js 24 + Hono:** API и задачи генерации.
- **LLM:** Ollama Cloud `gemma4:31b` как подтверждённый LIVE маршрут; другие маршруты выбираются пользователем при доступности.
- **Chromium checker:** HTML/JS, Canvas/WebGL, адаптивность, runtime и input observations.
- **SQLite:** версии, связь create/edit, checkpoints и восстановление.
- **Player:** opaque `iframe sandbox="allow-scripts"`, CSP и автономный HTML export.

Планируемое встраивание в native WebView — цель совместимости формата, а не заявленный результат физического WebView-теста.

## Слайд 6. Создавайте, сохраняйте и делитесь

- Библиотека и история версий хранятся на вашем сервере.
- Редактор передаёт модели текущий HTML и новое требование.
- HTML export позволяет открыть игру без сервера YAPLIX.
- Создание и изменение требуют доступной модели. Техническая проверка не гарантирует качество произвольной игровой механики.

## Слайд 7. Для людей и команд

- Генерация мини-игр под разную аудиторию.
- Текстовый запрос позволяет адаптировать механику, визуал и крупные элементы.
- Самостоятельный HTML облегчает дальнейшее встраивание в WebView.
- История версий и пользовательские изменения позволяют итеративно улучшать игру.
- LAN/QR и Arena — дополнительные сценарии для сохранённых совместимых игр; совместимость конкретного устройства проверяется отдельно.

## Слайд 8. От идеи к запуску

Показать: **выбор модели → ввод идеи → этап проверки/repair → сохранённая игра → управление → редактор/история → экспорт HTML**.

Сохранённые игры можно открывать без новой генерации. Для создания и редактирования нужно подключение к выбранной модели.
