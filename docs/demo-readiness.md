# Демонстрация YAPLIX за 3–5 минут

Покажите идею, настоящую игру, изменение и сохранение результата. Перед выступлением выберите версию и проверьте её на том же компьютере и телефоне. Этот сценарий — инструкция, а не отметка о состоявшейся репетиции.

## Подготовка

- Запустите интеграционный кандидат по [README](../README.md). Без ключей откройте авторскую аркаду — она подходит для показа приложения, но не доказывает LLM-генерацию.
- Для демонстрации LLM заранее подготовьте сохранённую версию с известными provider/model, job, versionId и hash. Не переименовывайте импортированный или авторский HTML в результат генерации.
- Свежая генерация и изменение расходуют обращения к модели. До репетиции согласуйте их бюджет, включая возможные повторы Ollama; один клик не обязательно равен одному POST. Для ChatGPT один job допускает не более одного inference POST.
- Проверьте телефон в доверенной сети, доступность 52604 и управление. Не меняйте Firewall на сцене и не показывайте секрет QR крупным планом.
- Подготовьте backup и автономный экспорт. Откройте экспорт offline и реально проверьте действия.

## Сценарий

| Время | Действие |
| --- | --- |
| 0:00–0:30 | «YAPLIX превращает описание в HTML5-игру». Покажите форму создания и библиотеку. |
| 0:30–1:30 | При согласованном бюджете отправьте идею, например: корабль собирает пять звёзд, избегает астероидов, управляется касаниями. Покажите фактический этап задания. |
| 1:30–2:30 | Откройте готовую игру. Если новая генерация ещё не завершилась, прямо скажите это и покажите заранее проверенную LLM-версию. Выполните реальные действия и Restart; не называйте ненаблюдавшийся финал пройденным. |
| 2:30–3:30 | Покажите историю: исходная и изменённая версии сохраняются отдельно. Новый edit во время выступления — только в согласованном бюджете. |
| 3:30–4:30 | Откройте выбранную версию по QR на телефоне; затем отключите доступ. Покажите скачивание автономного HTML. |
| 4:30–5:00 | Назовите ограничения: качество зависит от модели, технический gate не доказывает все правила, Arena включена в кандидат; качество произвольного HTML и античит не гарантируются. |

Если происхождение резервной LLM-версии не подтверждено, покажите авторский пример с честной подписью. Не выдавайте его за успешный новый запрос.

## Что подтверждено и что ещё предстоит

Исправление metadata Full HTML и строгий Canvas-контракт включены в main. Исторический блокер сохранения из аудита 18 октября устранён. Функции и проверки: [состояние продукта](release-status.md), [результат подготовки репозитория](repository-cleanup.md).

Свежая LIVE-репетиция на текущем кандидате, полная физическая матрица Android/iOS/WebView/Telegram и hosted release FULL не заявлены. Ubuntu — целевая система; Windows-прогон не доказывает работу на Ubuntu. Для офлайн-демо Arena: «Игры» → «Arena: Меткий бросок · офлайн» → «Общий рейтинг» → один QR → разные ники → пять бросков → рейтинг. Повторите партию и штатный restart с возобновлением комнаты. Заранее проверьте TCP52605 и частную сеть; [инструкция](arena.md), [настройка LAN](lan-network-setup.md). Реальный Apply/UAC требует отдельного разрешения владельца.
