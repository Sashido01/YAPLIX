# YAPLIX — обзор пользовательского сценария

YAPLIX превращает текстовую идею в автономную браузерную игру. Этот сценарий знакомит с основными возможностями приложения; [продуктовая презентация](presentation.html) дополняет обзор.

## От идеи к игре

1. Запустите YAPLIX и подключите свою модель по [инструкции](../INSTALL.md).
2. В разделе **Создать** выберите Ollama Cloud и опишите короткую игру.
3. Покажите этапы генерации и технической проверки. При подтверждённом исправимом дефекте ограниченное исправление выполняется той же моделью.
4. Откройте результат из уведомления или раздела **Игры**. Нажмите Start внутри игры и попробуйте управление.
5. Нажмите **Изменить**, сформулируйте новое требование и создайте следующую версию. Предыдущая останется в истории.
6. Скачайте HTML и откройте его в браузере. Для игры сервер YAPLIX не нужен; для нового изменения нужен.
7. Для совместимых игр откройте **Арена**; кнопка **На телефон** предоставляет временный QR-доступ в доверенной локальной сети.

## Если модель недоступна

Можно открыть ранее сохранённую игру, её историю и автономный HTML. Создание новой игры и редактирование требуют доступного провайдера. Не следует выдавать открытие сохранённой версии за новую генерацию.

## Частые вопросы

**Как появляется игра?** Модель создаёт полный HTML с CSS и JavaScript по пользовательскому запросу.

**Что проверяет YAPLIX?** Формат, ограничения безопасности и наблюдаемое исполнение в Chromium. Такая проверка не гарантирует полноценную игровую механику произвольного ответа модели.

**Где данные?** Игры и версии — в SQLite на сервере. Ключ модели остаётся у backend. Игровой код исполняется в opaque sandboxed iframe с CSP.

**Можно ли играть на телефоне?** Интерфейс адаптирован для небольших экранов и touch. QR-доступ требует работающего сервера и доверенной сети; физическая совместимость конкретного устройства проверяется отдельно.

**Как передать игру?** Скачайте один HTML-файл. Получатель может открыть его в браузере без сервера YAPLIX.
