Использован отдельный чистый clone без `.env`, пользовательских игр и SQLite; `npm ci` устанавливал зависимости из локального download cache. Штатный launcher `npm run app -- --no-open`, отдельные порты и новая пустая база. Игра открыта через обычную gallery и сыграна обычными кликами; счёт или состояние не подставлялись. Экспорт побайтово совпал с сохранённым HTML и сыгран как локальный файл offline; после штатного restart версия и hash сохранились.

Оба изображения просмотрены. Это настоящие screenshots, без генерации, ретуши или замены интерфейса. Мобильный профиль — эмуляция, не физический телефон. Авторская игра — authored/unverified, не LLM-результат. Внешняя генерация, OAuth, Telegram и применение Firewall не запускались. QR-секретов и пользовательских данных на снимках нет.
