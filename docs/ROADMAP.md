# Дорожная карта YAPLIX

**Актуальная версия:** [v0.0.1](https://github.com/Sashido01/YAPLIX/releases/tag/v0.0.1) · **Обновлено:** 29 октября 2026 года.

YAPLIX превращает текстовый запрос в автономную HTML5-игру, позволяет запускать её в браузере, сохранять версии, редактировать через LLM и делиться результатом. Дорожная карта показывает направления развития продукта, а не обещает даты выпуска. Реализация будущих функций зависит от подтверждённых результатов, ресурсов и качества тестов.

## Уже реализовано — v0.0.1

- Генерация игры по обычному тексту через LLM, техническая проверка и ограниченное автоматическое исправление.
- Canvas/WebGL, изолированный проигрыватель, автономный HTML-экспорт и запуск сохранённой игры без сервера.
- Редактирование игры через LLM, библиотека, история версий и сохранение в SQLite.
- Локальный QR-доступ и Arena с рейтингом для **совместимых** игр.
- Установщики Ubuntu Lite и Windows Lite/Full, документация и автономная презентация.

**Границы подтверждения:** на реальных LLM-ответах проверены отдельные пользовательские сценарии; технический PASS не гарантирует корректность механик каждой будущей игры. Для генерации нужен доступ к выбранной модели. Нативные Android WebView/iOS WKWebView и физические мобильные устройства не прошли отдельную полную приёмку.

**Приоритет:** сначала ошибки, влияющие на получение и запуск рабочей игры; затем UX и качество сгенерированного результата. Существующий релиз v0.0.1 сохраняется.

## v0.0.3 — Совместимость и удобство

- **WebView:** самостоятельный тест автономного HTML в настоящем Android WebView; WKWebView — при доступности устройства/окружения. Зафиксировать touch, ориентацию, offline, запуск/рестарт и ограничения. Браузерная эмуляция не подменяет native-тест.
- **Мобильная навигация:** проверить актуальный релиз на 320/390/430 px, включая изоляцию вкладок и восстановление позиции скролла. Исправлять только дефекты, подтверждённые на текущем `main`.
- **Управление и локализация:** улучшить подсказки генератору для удобных кнопок, отображения PAUSE/RESUME и языка интерфейса, заданного запросом; измерять результат по реальным играм.
- **Провайдеры:** Ollama Cloud остаётся основным проверенным маршрутом. OpenRouter Free — необязательный экспериментальный режим с динамической upstream-моделью; без доказательств стабильности не обещать для него надёжную генерацию или repair.
- **Обратная связь:** понятные сообщения при неполной проверке механик, сохранение диагностических материалов без публикации приватных игровых данных.

## v0.1.0 — Игровое развитие

Это направления исследований, **не функции текущего релиза**:

- **GameDNA / аналитика:** изучить, как подтверждённые события игры и результат реально помогают формировать следующий промпт — с контролем качества, приватности и без выдуманных метрик.
- **Жанровое разнообразие:** независимые LIVE-прогоны аркад, головоломок, гонок и других жанров с раздельным учётом first-pass acceptance, repair и игровой пригодности.
- **Графика и звук:** изучить автономную генерацию ассетов, которые можно безопасно встроить в один HTML без внешних сетевых зависимостей.
- **Социальные механики:** улучшать Arena по фактическому использованию, не заявляя честный античит или синхронный multiplayer без отдельной реализации.

## Как мы ведём работу

1. Новая Issue создаётся для подтверждённой проблемы или чётко обозначенного исследования; одна задача — один воспроизводимый результат и критерии приёмки.
2. Каждая правка идёт в отдельной ветке от актуального `main`, через PR и необходимые тесты. Работающий релиз и пользовательские данные не изменяются без необходимости.
3. Для исправления указываются исходный дефект, тест RED→GREEN, доказательства реального поведения, результат CI и ограничения.
4. `NOT_VERIFIED` означает недостаточно данных, а не автоматически исправность или неисправность. Физические устройства и LIVE-генерации отмечаются отдельно от unit/браузерной эмуляции.
5. Запланированные версии — ориентиры без фиксированных дат. Статус конкретной работы определяется связанной Issue/PR, а не одной строкой дорожной карты.
