# Статус редизайна UI-002 — фактическое состояние на 27 октября 2026

Локальная ветка `codex/arena-mvp`, база `e074974`. Ни один результат не опубликован
в GitHub. Исторические отчёты UI-002A–D описывают промежуточные состояния dirty-дерева
и не заменяют этот файл и [release status](release-status.md).

## Структура интерфейса

- **Создать** — идея, модель, рабочее пространство (генерация, анимация, запуск,
  редактирование следующей версии), диагностика и история заданий в раскрываемых секциях.
- **Игры** — единая библиотека сохранённых версий и авторских офлайн-игр.
- **Арена** — комнаты, QR, участники, рейтинг (существующий backend Arena, без новых контрактов).
- Отдельной вкладки «Игра» нет: игры запускаются из рабочего пространства кнопкой
  «Запустить игру». Отдельных страниц «Задания» и «Диагностика» как обязательного
  способа работы нет: «Задания» — архивная копия списка в сервисном разделе.

## Генератор: реализовано

- Поле идеи с placeholder «замути змейку для бабушки», запуск настоящего задания
  (`POST /api/jobs` с idempotency key).
- Этап/время/попытки/провайдер из `GET /api/jobs`; лёгкая CSS-анимация в правом поле
  во время работы; отмена видна в рабочем оверлее и в подробностях задания.
- Машина `idle → working → ready / failed / cancelled` по отслеживаемому заданию;
  чужие задания область не перезаписывают; порога 60 секунд нет.
- Ошибка показывает реальный текст и код; уведомления не накапливаются, важные
  остаются до закрытия; «Игра сохранена. Можно играть» — только после открытия версии.
- Редактирование: режим «Изменить»/«К игре» без одновременного огромного iframe
  и раскрытого редактора; содержимое полей при переключении сохраняется.
- История заданий, диагностика системы, аналитика версий — раскрываемые секции.

## Не подтверждено (не заявлять как готовое)

- Функциональная приёмка полной генерации через LLM: PARTIAL (см. [release status](release-status.md)).
- Экспорт, мобильное подключение с физического устройства, Arena с реальными
  участниками, восстановление активных заданий после перезагрузки.
- Ошибки Arena локализованы в клиенте (см. [known-errors](known-errors.md#ui-002f-сырой-код-arena_unsupported-поверх-интерфейса-27-октября-2026)),
  но поведение при редких кодах проверено только чтением кода, не живым запуском.
- Typecheck/build проходят, но корректность всей программы этим не доказывается.
- Windows в текущем цикле не проверялась; macOS — неподтверждённая платформа.
- В БД есть реальные failed/needs_attention задания — это не основание их изменять
  или очищать; старые задания рабочую область самопроизвольно не занимают.
