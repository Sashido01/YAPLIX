# Готовность к защите

На 21 октября 2026 репозиторий приватный; эта подготовка не является публичным релизом.

| Область | Состояние / следующий шаг |
| --- | --- |
| Суть продукта, запуск, навигация | [README](../README.md) и [документация](README.md) |
| Команда и вклад | Два участника, [AUTHORS](../AUTHORS.md) |
| Реальные изображения | [Снимки приложения и происхождение](media/README.md) |
| Проверки чистого клона и секретов | Результаты и точные ограничения в [отчёте интеграции](release-integration.md) |
| LLM-демонстрация | Есть исторические результаты; свежая репетиция выбранной версии ещё требуется |
| Физические платформы | Сообщения владельца имеют ограниченный scope; полная Android/iOS/WebView/Telegram матрица не закрыта |
| Arena, LAN setup, оформление | Единый кандидат, [проверки и оставшиеся шаги](release-integration.md) |
| Hosted CI и release | Actions приостановлены; перед release нужен разрешённый FULL на точном commit |
| Лицензия | Открытая лицензия не предоставлена; [решение о правах](licensing.md) отдельно |
| Сценарий защиты | [3–5 минут](demo-readiness.md), нужна реальная репетиция |

Чистый список Issues/PR сам по себе не означает готовности продукта. Незавершённые функции нельзя объявить завершёнными ради нулевого счётчика.
