# Критерии готовности для публичного портфолио

Этот список — план, а не отчёт о выполнении. Отмечайте пункты только при наличии подтверждения в репозитории.

YAPLIX сейчас Private. Этот чеклист относится к возможной будущей подготовке материалов и не разрешает менять видимость репозитория.

## Репозиторий

- [ ] Указаны окончательные название, суть продукта и задача пользователя.
- [ ] README показывает реальное решение, а не только описание соревнования.
- [ ] Добавлены подтверждённые участники и их конкретный вклад.
- [ ] Определены лицензия и условия публикации материалов.

## Рабочий результат

- [ ] Приложение или сервис воспроизводимо запускается по инструкции.
- [ ] Есть демонстрационные данные без личной/закрытой информации.
- [ ] Показан проверяемый сценарий от задачи до результата.
- [ ] Зафиксированы ограничения, известные проблемы и дальнейшие шаги.

## Инженерные практики

- [ ] Описаны архитектура, ключевые компромиссы и зависимости.
- [ ] Есть автоматические тесты и инструкция запуска проверок.
- [ ] CI действительно работает, статус подтверждён GitHub Actions.
- [ ] Pull Requests или коммиты позволяют проследить вклад участников.
- [ ] Исключены секреты, чувствительные данные и неразрешённые материалы.

## Защита и демонстрация

- [ ] Подготовлены скриншоты/видео реального работающего прототипа.
- [ ] Создан воспроизводимый релиз с версией.
- [ ] Проработаны вопросы о ценности, рисках, масштабировании и ограничениях.

**Правило:** не подменять результат красивыми бейджами, скриншотами макета или выдуманными тестами.
