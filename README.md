# YAPLIX — ты придумал, теперь играй

Браузерные игры из текстовой идеи: создайте игру с помощью ИИ, сыграйте и измените правила следующим сообщением.

## Что можно сделать

YAPLIX помогает быстро проверить игровую идею без ручной сборки проекта. Модель пишет самостоятельный HTML5-документ со встроенными CSS и JavaScript. Сервер проверяет его, сохраняет версию и открывает игру в изолированном окне.

- **Придумать и создать.** Опишите мир, правила и управление. Генерация идёт в фоне; состояние задания и черновик остаются на сервере.
- **Сыграть на компьютере или телефоне.** Для телефона есть временный QR-доступ к одной сохранённой версии в доверенной локальной сети.
- **Устроить соревнование.** Откройте «Общий рейтинг»: один QR, разные ники, независимые партии и сохранённые рекорды. Нужна Arena-совместимая версия с настоящим счётом и завершением.
- **Подготовить частную сеть.** Диагностика Windows ничего не меняет; настройка узких правил Firewall требует просмотра плана, отдельного согласия и UAC.
- **Изменить игру.** Например, попросить добавить противников или новую цель. Модель получает весь исходный HTML, а предыдущие версии остаются в библиотеке.
- **Сохранить результат.** Переключайтесь между версиями, скачивайте автономный HTML, делайте проверяемые резервные копии SQLite.
- **Открыть через Telegram.** Mini App использует тот же интерфейс; нужны собственный бот, HTTPS и настройка доступа владельца.

Сценарий: **придумать → создать → играть → изменить → поделиться**. [Arena](docs/arena.md) с одним QR и общим рейтингом включена в этот кандидат. Для демонстрации без ключей выберите «Arena: Меткий бросок · офлайн». Неподдерживаемым играм счёт не придумывается.

## Установка и запуск

Репозиторий приватный: для клонирования нужен доступ. Требуются Git и **Node.js 24.18+ в ветке 24.x** с npm. Команды одинаковы в Windows PowerShell и Ubuntu 24.04:

```sh
git clone https://github.com/Sashido01/YAPLIX.git
cd YAPLIX
git switch --track origin/codex/release-integration-001
npm ci
npm run app
```

Команда `git switch` выбирает этот кандидат для ревью: main пока не включает интеграцию. После его принятия обычная установка сможет использовать main.

Launcher соберёт приложение и откроет браузер. Обычно адрес — `http://127.0.0.1:3000/`; при другом порте используйте адрес из терминала. На Windows после установки можно запускать **YAPLIX.cmd** двойным щелчком. Для запуска без открытия окна: `npm run app -- --no-open`.

**Без ключа** откройте «Игры» и выберите авторскую аркаду. Для **новой генерации** создайте `.env` по [.env.example](.env.example), только если своего файла ещё нет, задайте серверный ключ выбранного провайдера и установите проверяющий браузер:

```sh
npm run checker:install
npm run doctor:providers
```

| Провайдер | Условия |
| --- | --- |
| Ollama Cloud | Основной маршрут: `gemma4:31b`, серверный `OLLAMA_CLOUD_API_KEY` |
| OpenRouter Free | Ручной экспериментальный выбор: `openrouter/free`, серверный `CLOUD_API_KEY`; доступность зависит от бесплатной квоты |
| ChatGPT | Личная сессия только на этом компьютере: `gpt-6.1-sol`, medium, один запрос к модели на задание; [подключение и границы проверки](docs/chatgpt-setup.md) |

Ключи не передаются в браузер или HTML игры. Доступность провайдера и время генерации не гарантируются. Автоматического перехода на платную модель или другой провайдер нет.

## Как устроено

**Браузер / Telegram → Hono API → генерация полного HTML → статическая и браузерная проверка → SQLite → изолированная игра.**

Сервер — Node.js и TypeScript; интерфейс собирается esbuild без UI-фреймворка. Проверка использует Chromium/Playwright. Игры запускаются в opaque iframe с CSP; игровой код не исполняется в Node. Телефон получает лёгкий браузерный клиент, сервер и модель работают отдельно.

Для новых результатов весь видимый мир и интерфейс игры должны рисоваться в **Canvas 2D/WebGL**. Старые версии читаются и экспортируются без переписывания. [Архитектура](docs/architecture.md), [контракт валидации](docs/game-validation.md).

## Проверенные результаты и ограничения

Релиз-кандидат содержит генерацию и изменение HTML5, задания с восстановлением, библиотеку и историю версий, экспорт, backup, локальный QR и Telegram-интеграцию. Исправление контракта метаданных уже включено; прежний блокер сохранения Full HTML больше не является текущим статусом.

Автоматические проверки покрывают сохранение и повторное открытие SQLite, авторизацию, изоляцию игры, экспорт, управление и мобильные размеры. **Техническая проверка не доказывает правильность любых правил, победы или поражения.** Итоги этой подготовки и точные границы: [проверки интеграции](docs/release-integration.md).

Реальные обращения к LLM подтверждены датированными отчётами; новый LIVE-прогон в этой подготовке не выполнялся. Android/Brave с QR проверял владелец. Также он сообщил об Arena на двух физических телефонах после ручного правила TCP52605: два игрока, по 150 очков. Это проверка прежнего #53, не нового кандидата или LAN helper; полной приёмки iOS, WebView и Telegram нет. Hosted Actions временно отключены владельцем; локальные тесты не означают зелёный CI. Публичного релиза и персональной изоляции библиотек разных пользователей пока нет.
