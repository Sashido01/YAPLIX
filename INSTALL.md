# Установка YAPLIX в Ubuntu

> **Клонировали код из GitHub?** Для запуска исходников portable-инсталлятор не требуется. Выполните шаги в [README](README.md): Node 24.18+, `npm ci`, `npm run app`. Описанные ниже Lite/Full `.run` — отдельные локальные сборки, а не файлы, автоматически доступные при клонировании GitHub.

Сборочные скрипты создают два portable-файла для **Ubuntu 24.04, x86-64**. Готовые
бинарные пакеты не входят в Git; их нужно собрать или получить отдельно. Они ставят YAPLIX
только в вашу пользовательскую директорию. Права администратора, системный Node.js,
изменения библиотек, настроек ОС или интернет для установки не нужны.

## Первый запуск

1. Получите собранный **Lite**-пакет и откройте его — около **36 МБ** в проверенной локальной сборке.
2. Если Ubuntu предлагает выбрать действие, нажмите **Запустить**. Если запуск
   запрещён, разрешите выполнение только для скачанного файла.
3. Установщик сам проверит Ubuntu и защищённый запуск браузерного валидатора,
   подготовит YAPLIX в вашем профиле и откроет приложение в браузере.

Lite использует уже установленный Google Chrome, если он проходит проверку.
Chrome не устанавливается и не меняется. Если его нет или защищённая проверка
не проходит, Lite остановится без изменения данных и предложит попробовать
**Full** — существенно больше Lite, с отдельными Chromium и headless-shell. Автоматически скачать Full
установщик не может: поставки работают без интернета. Если политика Ubuntu
запрещает защищённый Chromium, обе поставки сообщат об этом и остановятся;
отключать защиту не нужно.

## Повторный запуск и данные

После установки открывайте **YAPLIX** из меню приложений. Повторная установка
той же версии использует уже подготовленные компоненты. Обновление сохраняет
предыдущую программу и создаёт резервную копию базы до переключения версии.
При неудаче установщик возвращает прежнюю версию; базу поверх ваших данных
автоматически не восстанавливает.

Игры, версии и настройки хранятся отдельно от программы: обычно в
`~/.local/share/yaplix`. Не удаляйте эту папку при обновлении и не копируйте
работающую SQLite вручную.

## Если запуск не удался

Установщик показывает понятную причину и предлагает повторить действие, когда
это безопасно. Журнал: `~/.local/share/yaplix-program/installer/install.log`.
При проблеме с Lite используйте Full. Если не запускается и Full, передайте
организатору сообщение установщика и журнал; системные настройки вручную не
меняйте.

На текущей Ubuntu 24.04 проверены запуск установщика, защищённый Chrome и Chromium,
установка, повторный запуск и сохранение игры. Чистое независимое устройство
не проверялось (**NOT_VERIFIED**). Эта инструкция описывает Ubuntu; другие
платформы в данной проверке не участвовали.

Для сборки и технических деталей: [руководство установщика](docs/installer-building.md).
