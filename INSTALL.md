# Установка YAPLIX: Ubuntu и Windows

Кандидат сдачи 29 октября находится в ветке `codex/submission-009` ([Draft PR #69](https://github.com/Sashido01/YAPLIX/pull/69)); до merge старый main не представляет локальную версию. [Короткий путь создания игры и скриншоты](README.md).

> **Клонировали код из GitHub?** Выполните `sh install.sh` в Ubuntu или откройте `YAPLIX.cmd` в Windows. Bootstrap подготовит проверенный изолированный Node и передаст пакет общему мастеру. На Ubuntu он выбирает Lite при совместимом Google Chrome, иначе Full с закреплёнными Chromium и headless-shell. Нужен чистый Git-клон. Первый запуск исходников обычно требует сеть для npm и браузера, если их нет в проверенном кэше. Готовые `.run`/`.exe` автономны и не входят в Git.

Сборочные скрипты создают Lite/Full для **Ubuntu 24.04 и Windows 10/11, x86-64** на соответствующих сборочных хостах. Готовые
бинарные пакеты не входят в Git; их нужно собрать или получить отдельно. Они ставят YAPLIX
только в вашу пользовательскую директорию. Права администратора, системный Node.js,
изменения библиотек, настроек ОС или интернет для установки не нужны.

При отсутствии сети можно указать локальный официальный архив Node через
`YAPLIX_BOOTSTRAP_ARCHIVE` и запустить bootstrap с `YAPLIX_INSTALL_OFFLINE=1`:
npm возьмёт пакеты только из ранее заполненного личного кэша. Если кэша нет,
установка исходников остановится без изменения приложения. Без Chrome для Full также нужны проверенные Chromium и headless-shell в локальном Playwright-кэше или в личном кэше архивов bootstrap; иначе нужна сеть. Готовые Lite/Full
пакеты устанавливаются автономно. Переменные `HTTP_PROXY`, `HTTPS_PROXY` и
`NO_PROXY` используются текущими `curl`/npm; `NODE_EXTRA_CA_CERTS` передаёт доверенный сертификат также `curl`. При ошибке загрузки проверьте
DNS, TLS и маршрут без отключения проверки сертификатов.

## Первый запуск

1. Получите собранный **Lite**-пакет и откройте `.run` в Ubuntu или `.exe` в Windows. Ubuntu Lite занимает около **36 МБ** в проверенной локальной сборке.
2. Если Ubuntu предлагает выбрать действие, нажмите **Запустить**. Если запуск
   запрещён, разрешите выполнение только для скачанного файла.
3. Установщик сам проверит Ubuntu и защищённый запуск браузерного валидатора,
   подготовит YAPLIX в вашем профиле и откроет приложение в браузере.

Lite использует уже установленный Google Chrome, если он проходит проверку.
Chrome не устанавливается и не меняется. Если его нет или защищённая проверка
не проходит, Lite остановится без изменения данных и предложит попробовать
**Full** — существенно больше Lite, с отдельными Chromium и headless-shell. Автоматически скачать Full
установщик не может: поставки работают без интернета. Если политика Ubuntu
запрещает защищённый Chromium, обе поставки сообщат об этом и остановятся;
отключать защиту не нужно.

Из клона Ubuntu установщик сам выбирает Full, если Chrome отсутствует или не
проходит защищённую проверку. Он проверяет SHA256 локального браузерного кэша
или загружает закреплённые архивы через текущий proxy с проверкой TLS и SHA256.
При недоступной сети и пустом кэше используйте готовый Full-пакет.

## Создание первой игры

1. В меню приложений откройте **Настроить AI YAPLIX**. Выберите **Ollama Cloud** и введите свой API-ключ. Ключ хранится в личном профиле; его не нужно отправлять проверяющему или в Git.
2. Перезапустите **YAPLIX**. В «Модель и настройки» выберите **Ollama Cloud · gemma4:31b**.
3. В разделе **Создать** опишите простую игру и нажмите **Создать игру**. Дождитесь результата проверки; генерация зависит от сети и модели.
4. Откройте результат из уведомления или раздела **Игры**. Попробуйте Start и управление, затем **Изменить** и **Скачать HTML**.

Без подключённой модели новые игры не создаются. Библиотека на чистой установке пуста; ранее сохранённые игры можно открывать без генерации. Для исходников ключ задаётся в `.env` — [пример в README](README.md#подключить-модель).

## Повторный запуск и данные

После установки открывайте **YAPLIX** из меню приложений. Повторная установка
той же версии использует уже подготовленные компоненты. Обновление сохраняет
предыдущую программу и создаёт резервную копию базы до переключения версии.
При неудаче установщик возвращает прежнюю версию; базу поверх ваших данных
автоматически не восстанавливает.

Игры, версии и настройки хранятся отдельно от программы: обычно в
`~/.local/share/yaplix`. Не удаляйте эту папку при обновлении и не копируйте
работающую SQLite вручную.

## Если запуск не удался

Установщик показывает понятную причину и предлагает повторить действие, когда
это безопасно. Журнал: `~/.local/share/yaplix-program/installer/install.log`.
При проблеме с Lite используйте Full. Если не запускается и Full, передайте
организатору сообщение установщика и журнал; системные настройки вручную не
меняйте.

На текущей Ubuntu 24.04 проверены запуск установщика, защищённый Chrome и Chromium,
установка, повторный запуск и сохранение игры. Чистое независимое устройство
и реальный Windows запуск не проверялись (**NOT_VERIFIED**).

Для сборки и технических деталей: [руководство установщика](docs/installer-building.md).
